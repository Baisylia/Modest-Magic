# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.3.2] - 2026-09-01

### Changed

- Added `#modestmagic:enchantable/tablet` for items that can be enchanted with tablets in the smithing table (fixes
  issues with Enderscape mirrors).

## [1.3.1] - 2026-07-16

### Fixed

- Adjusted default enchantment compatibility.
- Fixed auto-generated tooltip not working for certain enchantments.

## [1.3.0] - 2026-06-06

### Added

- Added custom tooltips for tablets, with Enchantment Descriptions/Item Descriptions integration.

## [1.2.2] - 2026-05-13

### Changed

- Altars will no longer show their cloth when a block is placed directly above them (they're now better for
  decoration!).

### Fixed

- Fixed high-pitched glitch in sounds (wtf Audacity).
- Fixed accidental face culling for one specific orientation of pillar.

## [1.2.1] - 2026-05-12

### Fixed

- Fixed the cloth in the Altar model not being properly cut out.
- Fixed sounds not playing when placing Altars sideways.
- Fixed invisible output entities in EMI summoning recipes.
- Fixed issues with summoning sounds.

## [1.2.0] - 2026-05-12

### Changed

- Reworked EMI smithing plugin for parity with EMI's anvil enchanting plugin.

## [1.1.0] - 2026-05-11

### Fixed

- Corrected link to mod GitHub.
- Fixed Netherite gear not being enchantable with Tablets.

## [1.0.0] - 2026-05-11

- Initial release.
